# chadmanes.github.io

One-page portfolio for Chad Manes, Senior Content Producer. Served by GitHub Pages from `main` / root.

- Edit the About blurb in `index.html` (marked `EDIT ME`).
- Replace the LinkedIn `PLACEHOLDER` link with the exact profile URL.
- To add a sample: in a `.card`, set `href`, title, blurb, remove the `placeholder` class, and optionally add a thumbnail image.
- Custom domain (later): add a `CNAME` file containing `chadmanes.com`, set it in repo Settings > Pages, then update DNS at Bluehost.
